# Signal Weekly: Beehiiv Sample Library Delivery Guide

This guide gives the owner the exact non-technical delivery path for the hybrid Sample Library. It uses the existing Beehiiv **Welcome Email** and one manual weekly email; it does not require a paid automation sequence.

## 1. Update the Welcome Email

In Beehiiv, open **Settings → Publication → Email → Welcome Email**. Keep the existing welcome email enabled and add the following section after its opening welcome message.

> **Your starter working page**
>
> Start with **Evidence Before Adjectives**, a complete Sample Library working page for turning broad résumé claims into credible evidence.
>
> **Read the complete sample:** https://files.manuscdn.com/user_upload_by_module/session_file/310519663899346819/ZmOykZqdoDULaVlo.pdf
>
> This is a sample briefing edition prepared for practical reading. It is not a historic newsletter issue and does not guarantee a career outcome.

The welcome email is sent after a reader confirms their subscription. This delivers an immediate, useful first file while the public website continues to show the full preview library.

## 2. Send One Manual Email Each Week

Each week, create **one** Beehiiv post/email. Include your current Signal Weekly insight first, then add the scheduled item from `sample-issues/DELIVERY_SCHEDULE.md` using this repeated block.

> **From the Sample Library**
>
> This week’s working page is **[TITLE]**. It is a sample briefing edition prepared for practical reading—not a historic issue—and includes one focused worksheet for your next career decision.
>
> **Download the complete working page:** [PASTE THE SCHEDULED PDF LINK]

For the weekly sequence, start at **Sample Briefing 02** because Briefing 01 is delivered in the welcome email. Leave at least seven days between sample-library deliveries. Do not send a second standalone email simply for the PDF; placing the working page beneath the weekly Signal keeps the cadence valuable without creating inbox fatigue.

## 3. Accuracy Checklist

Before sending, confirm that the email says **“From the Sample Library”** and does not call the document a newly issued newsletter. Ensure the title and link match the delivery schedule. When you begin publishing genuinely new issues, use a distinct label such as **“This week’s Signal”** for the new material.

## 4. Future Improvement

The present approach is deliberately manual and works with the existing Beehiiv configuration. A timed, per-subscriber release sequence would require a future Beehiiv automation capability or a managed protected-download workflow; do not promise individual timed unlocking until that feature is configured and tested.
